# Visual AI Skills

两个 Codex skills 的完整安装包，保留 SKILL.md 及所有配套参考、脚本、模板、schema、测试和评测文件，排除 Python 缓存。

## 下载与安装

- [directing-presentation-visuals.zip](directing-presentation-visuals.zip)：演示文稿视觉方向、代表页、预览、视觉一致性和 PowerPoint 渲染验收。
- [visual-ai-development-governance.zip](visual-ai-development-governance.zip)：视觉 AI 开发的需求与决策记忆、失败边界、Provider 验证及 Git 成熟度治理。

下载所需 ZIP，解压后将其中同名文件夹放入自己的 Codex skills 目录。阅读文件夹内的 SKILL.md 使用。
